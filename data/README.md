# Данные эксперимента

Файлы ниже лежат в этой папке и доступны для просмотра непосредственно на GitHub. В JSONL каждая строка соответствует отдельной записи или попытке. Пустые неприменимые числовые значения обозначены `null`.

| Файл | Содержимое |
| --- | --- |
| `v2_per_track_metrics.jsonl` | 8 736 записей пяти моделей. Ключ `model_id`, `duration_s`, `prompt_id`, `set_idx`, `track_idx`. `v1` хранит результаты спектральной проверки и фильтра, `click_naive` и `grid_naive` — признаки щелчка и сетки целой записи. |
| `generation_manifest.jsonl` | Попытки генерации, в том числе фанфары. Параметры, сиды, время и пик видеопамяти. `wav_path` — относительный путь к исходному файлу из прогона. |
| `eval_summary_30s.json`, `fad_kad_reference_meta.json` | Сохранённые FAD/KAD для 30 с и описание референса NES-VMDB. В JSON KAD записан до умножения на 100. |
| `v2_sets_metrics.jsonl` | Признаки 288 записей опыта с заданным темпом. `naive` — целая запись, `beat_aligned` — обрезка по долям. |
| `review_extension_tracks.jsonl`, `review_extension_summary.json` | Сопоставленные случайные и подобранные обрезки. Границы, число долей, результаты проверки, длительность и причины отказа фильтра. |
| `tempo_follow_sa3_summary.json`, `tempo_follow_ace_summary.json` | Сводки опыта с заданным темпом, включая ошибки BPM и параметры генерации. |
| `nes_loop_index.json`, `nes_control_measurements.json` | Индекс 150 контрольных петель NES с границами и признаками. Разбиение встречается в поле `set` (`calib` / `test`) файла признаков. |
| `v2_summary.json`, `control_defects.csv`, `degeneracy_thresholds.json` | Сводка калибровки, тест с искусственными дефектами и пороги предварительного фильтра. |

Здесь опубликованы числовые признаки и метаданные. Исходные аудиозаписи и веса моделей нужны для повторного расчёта признаков. Исходный корпус — [NES-VMDB](https://github.com/rubensolv/NES-VMDB).
